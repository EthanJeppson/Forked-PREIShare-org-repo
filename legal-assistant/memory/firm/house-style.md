# House style

Analog of a code formatter + API style guide. Style never beats a hard_stop or a taken matter position.

- Party names: use the defined term from the lock (`Northwind`, not “the Company” unless defined that way).
- Efforts: `commercially reasonable efforts`. Do not introduce `best efforts` or `reasonable best efforts` on our paper.
- Shall vs will: `shall` for obligations, `will` for future facts.
- Including: `including without limitation` once in the interpretation section; do not spray it.
- Cross-references: `Section 1.2`, not “above.”
- Comments to counterparties: one ask per bubble; no internal severity labels.
- Memos: short sentences; put the answer first.
- Do not add Latin (`inter alia`, `mutatis mutandis`) unless the working document already uses it.
